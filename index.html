Политика конфиденциальности «Навь»

Действует с 17 октября 2026 г.

Коротко

«Навь» — однопользовательская игра. Игра не собирает и не хранит на серверах личные данные игрока. В версиях для Android с рекламой рекламный сервис Яндекса может получать технические данные устройства (см. ниже).

Какие данные использует игра

Прогресс игры (открытые карты, статистика забегов, настройки звука и т.п.) сохраняется только локально на устройстве игрока, во внутреннем хранилище приложения. Эти данные никуда не отправляются и недоступны разработчику.

Реклама и аналитика

В версиях игры для Android (с 1.1) показывается реклама через сервис Яндекс Реклама (Yandex Mobile Ads SDK): вознаграждаемые ролики по желанию игрока и межстраничные ролики между узлами карты. Для показа рекламы SDK может получать рекламный идентификатор устройства, IP-адрес и технические сведения об устройстве и приложении; обработка выполняется Яндексом по его собственной политикой конфиденциальности (yandex.ru/legal/confidential). Разработчик игры не получает эти данные и не использует их сам. Других трекеров и систем аналитики в игре нет.

Данные третьих лиц

Приложение не запрашивает доступ к контактам, геолокации, камере, микрофону или другим личным данным устройства.

Изменения политики

Если способ обработки данных изменится (например, при добавлении рекламы или облачных сохранений), эта страница будет обновлена, а дата вверху — изменена.

Nav — Privacy Policy

Effective October 17, 2026

Summary

Nav is a single-player game. The game does not collect or store personal data about the player on any server. In Android versions with ads, the Yandex ad service may receive technical device data (see below).

What data the game uses

Game progress (unlocked cards, run statistics, sound settings, etc.) is saved locally on the player's device only, in the app's internal storage. This data is never transmitted anywhere and is not accessible to the developer.

Ads and analytics

Android versions of the game (from 1.1) show ads through Yandex Ads (the Yandex Mobile Ads SDK): rewarded videos that the player chooses to watch, and interstitial ads between map nodes. To serve ads the SDK may receive the device advertising ID, IP address and technical device and app information; this data is processed by Yandex under its own privacy policy (yandex.com/legal/confidential). The game developer does not receive this data and does not use it. The game contains no other trackers or analytics services.

Third-party data

The app does not request access to contacts, location, camera, microphone, or any other personal device data.

Changes to this policy

If data handling changes in the future (for example, if ads or cloud saves are added), this page will be updated and the date above will change accordingly.
